Project mission

LUNA NAV is a student-built decision-support concept for lunar mission planning.

It aims to help users compare candidate lunar regions by bringing several planning questions into one clear interface:

  • When could a site receive useful sunlight?
  • When could Earth be above the local horizon?
  • How might terrain and local horizon features affect visibility?
  • How can mission planners compare sites transparently?

Core idea: combine lunar terrain data with Sun/Earth ephemerides and explain the assumptions behind every result.
